# User Stories

Feature: Musician Profile 
AS A musician user
I WANT to have a section of the app where I can build my profile, providing a profile picture, a bio, location, genres of music I play, and integration with Apple Music and Google Music to show case playlists or songs I can play as part of my set
SO THAT I can host users will be able to see my profile when applying for gigs.

Feature: Dashboard Home Page
AS A app user
I WANT a Dashboard home page that changes depending on toggle switch, switching between a musician user or a host user. As a musician user, it should show gigs in my area as a carousel as well as gigs happening soon. As a host, it should show gigs I’ve created, gigs I’ve previously created, and musicians who have applied for gigs I’m hosting
SO THAT I can have a central location for key app uses

Feature: Push Notifications
AS A musician user 
I WANT to be able to receive push notifications of a gig host who enabled their gig to be pushed to users, with a map showing the location and key details of the event, such as price, genre and sample songs they’d like in the set 
SO THAT I can apply for the event, sending my profile to the gig host so they can approve or deny

Feature: Gig Creation
AS A host user
I WANT to be able to create gig opportunities, setting the description, offered price, location, genres required, date and example songs I’d like in the set
SO THAT they can be shown to signed up musicians who may be suitable can apply for the gig, and I can review applications before choosing

Feature: Selected Gig Overview
AS A musician user
I WANT to be able to select a gig to see its full overview as set by the host, looking at its full description, location, price and example songs
SO THAT I can apply to play and have my profile reviewed by the host

Feature: Social Logins
AS A app user
I WANT to be able to sign up and login to the app via popular social logins, as a minimum Apple, Google and Facebook, as well as the option to sign up directly through the app itself
SO THAT logging in and signing up is quick and easy.
